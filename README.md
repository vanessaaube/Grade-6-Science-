# Matter Lab — Grade 6 Matter Quiz

A self-contained, responsive quiz website for reviewing Grade 6 matter and thermal energy.

## Run it

Open `index.html` directly in a browser, or serve this folder with any static web server.

Example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Included behavior

- 30 Grade 6 review questions across five topics
- Immediate right/wrong feedback when an answer is selected
- A concise explanation after every wrong answer
- Answers can be changed and are rechecked instantly
- Live progress and score updates
- Saved progress using browser local storage
- Reset controls at the top and end of the quiz
- Keyboard-friendly controls and accessible live feedback
- Responsive layouts for desktop, tablet, and phone

No build step is required.
